## 🍎 Overview

Sitio web y portafolio profesional desarrollado con un **diseño minimalista inspirado en el lenguaje visual de Apple (Apple Keynote & Bento Grid)**. Optimizado para máxima velocidad de carga, diseño responsivo y experiencia de usuario fluida con cambio dinámico de modo oscuro/claro.

---

## ✨ Características Principales

* 🌓 **Modo Oscuro y Claro Inteligente:** Toggle animado con transición fluida entre Sol y Media Luna, persistencia en `localStorage` y detección automática de preferencia de sistema (`prefers-color-scheme`).
* 🧊 **Apple Glassmorphism:** Barra de navegación flotante y tarjetas con desenfoque de fondo (`backdrop-blur`) y bordes semi-transparentes de alta definición.
* 🍱 **Bento Grid Layout:** Cuadrícula moderna para presentar especialidades técnicas, métricas de impacto y stack de producción.
* ⚡ **Ultra Ligero & Zero Bloatware:** Construido con HTML5 semántico, Tailwind CSS y JavaScript vanilla optimizado para rendimiento 100/100.
* 📋 **Interacción Rápida:** Botón interactivo para copiar correo electrónico al portapapeles con feedback visual instantáneo.
